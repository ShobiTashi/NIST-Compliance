# Overview
This directory contains the organisation’s full compliance management framework, aligned with ISO 27001, NIST CSF 2.0, SOC 2, HIPAA, GDPR, and PCI DSS

The purpose of this folder is to provide a complete and reusable compliance assessment model that demonstrates practical GRC capability for engineering-driven organisations.

## 4. Compliance Obligations
HIPAA: United States law covering protected health information held by covered entities and business associates.
GDPR: European Union regulation covering personal data of individuals in the EU.
PCI DSS: Payment card industry standard covering stored, processed, or transmitted cardholder data.
SOC 2: AICPA attestation. An independent CPA issues a report with an opinion. Type I covers design at a point in time, Type II covers design and operation over a period.
ISO 27001:	International standard. An accredited body issues a certificate for a conforming management system.
NIST CSF:	Voluntary outcome-based framework. Posture is expressed as a current profile and a target profile.
	
PCI DSS validation reference	
Report on Compliance	Required for the highest merchant and service provider volumes, performed by a Qualified Security Assessor.
Self Assessment Questionnaire	Available to lower volume organizations only.
