# NIST CSF 2.0 Compliance Assessment Framework for Skypea Corporation

# Overview
This directory contains the organisation’s full compliance management framework, aligned with NIST CSF 2.0, which is a voluntary outcome-based framework. Posture is expressed as a current profile and a target profile.

The purpose of this folder is to provide a complete and reusable compliance assessment model that demonstrates practical GRC capability for engineering-driven organisations.

## 5. Gap sample
A few top-priority gap samples were taken from the compliance assessment to highlight recommended action steps to close the gaps:

* Enforce MFA on all administrative accounts and eliminate password-only sign-in (PR.AA). Owner: CISO. Near-term.
* Implement backup integrity verification and scheduled restore testing (RC.RP-03). Owner: Platform engineering. Near-term.
* Build a prioritized supplier inventory and pre-contract due-diligence process (GV.SC). Owner: CISO with procurement. Medium-term.
* Create an incident notification runbook mapping contractual timeframes to concrete steps (RS.CO). Owner: CISO. Near-term. Aggregate logs into central monitoring with scheduled review (DE.CM). Owner: Platform engineering. Medium-term.
