# NIST CSF 2.0 Compliance Assessment Framework for Skypea Corporation

# Overview
This directory contains the organisation’s full compliance management framework, aligned with NIST CSF 2.0, which is a voluntary outcome-based framework. Posture is expressed as a current profile and a target profile.

The purpose of this folder is to provide a complete and reusable compliance assessment model that demonstrates practical GRC capability for engineering-driven organisations.

## 4. Control Test Results
The Recorded Result is entered and is not independently checked. A test with one or more exceptions cannot be concluded as a pass.	

A complete finding carries five elements:

**Condition**: The factual state the auditor observed.

**Criteria**:	The standard the subject is measured against.

**Cause**:	Why the gap came to exist.

**Effect**:	The consequence and risk the gap creates.

**Recommendation**:	The action proposed to close the gap.
